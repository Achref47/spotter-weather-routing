# Deployment on Render

Two services are defined in `render.yaml`: `spotter-api` (Django + Gunicorn) and `spotter-web`
(static Vite build). Nothing secret is stored in the repository.

## Environment variables

| Variable | Service | Secret | Where it is set | Value / format |
|---|---|---|---|---|
| `DJANGO_SECRET_KEY` | api | **yes** | Render dashboard (prompted) | At least 50 characters. Generate: `python -c "import secrets; print(secrets.token_urlsafe(50))"` |
| `DJANGO_DEBUG` | api | no | `render.yaml` | `false`. The app refuses to start on Render if debug is on. |
| `DJANGO_ALLOWED_HOSTS` | api | no | Render dashboard (prompted) | API hostname only, no scheme: `REPLACE-WITH-API-HOST.onrender.com` |
| `CORS_ALLOWED_ORIGINS` | api | no | Render dashboard (prompted) | Static site origin: `https://REPLACE-WITH-WEB-HOST.onrender.com` (no trailing slash; comma-separate several) |
| `MAPBOX_TOKEN` | api | **yes** | Render dashboard (prompted) | Your Mapbox token. Used server-side for routing only. |
| `NUM_PROXIES` | api | no | `render.yaml` | `1`. Used by the throttle to find the client address. Verify below. |
| `PYTHON_VERSION` | api | no | `render.yaml` | `3.11.9` (the version used in development) |
| `VITE_API_URL` | web | no (public, baked into the JS) | Render dashboard (prompted) | `https://REPLACE-WITH-API-HOST.onrender.com` (no trailing slash) |
| `NODE_VERSION` | web | no | `render.yaml` | `22.22.2` (Vite 8 needs Node 20.19+ or 22.12+) |
| `OPEN_METEO_MODEL` | api | no | not set | Defaults to `ecmwf_ifs025` in code. Set only to override. |
| `ANALYZE_RATE_BURST`, `ANALYZE_RATE_HOUR` | api | no | not set | Default `10/min` and `30/hour` per client. |
| `VITE_MAP_STYLE` | web | no | not set | Defaults to the OpenFreeMap "liberty" style. |

`DJANGO_SECRET_KEY` is prompted rather than generated by Render because Render's generated value is
shorter than the 50 characters `config/settings.py` requires.

## Steps

1. Push to GitHub (you do this). Confirm `render.yaml` is at the repository root.
2. In Render: **New > Blueprint**, pick the repository, and approve the two services.
3. Render prompts for each secret/URL variable. The final hostnames are only shown after the services
   exist, so enter these and correct them in step 5 if they differ:
   - `DJANGO_ALLOWED_HOSTS` = `spotter-api.onrender.com`
   - `CORS_ALLOWED_ORIGINS` = `https://spotter-web.onrender.com`
   - `VITE_API_URL` = `https://spotter-api.onrender.com`
   - `DJANGO_SECRET_KEY` and `MAPBOX_TOKEN`: paste the values; never write them in a file or chat.
4. Wait for both deploys.
5. Open each service in the dashboard and copy its real `onrender.com` URL. If a name was already
   taken, Render adds a suffix, so the three URL variables above must be updated. Changing
   `VITE_API_URL` needs a **manual redeploy of `spotter-web`**, because it is read at build time.

## Verify (nothing here is verified until you have run it)

```powershell
# 1. Health. Expect {"status":"ok"} and HTTP 200. The first call can be slow while the service wakes.
curl.exe -i https://YOUR-API-HOST.onrender.com/api/health

# 2. Open https://YOUR-WEB-HOST.onrender.com in a private window; run Houston -> Atlanta.
#    A CORS or "Cannot reach the server" error means CORS_ALLOWED_ORIGINS or VITE_API_URL is wrong.

# 3. NUM_PROXIES / throttle check without spending upstream quota (an empty body is rejected with
#    400 AFTER the throttle runs, so no geocoding, routing or weather call happens):
1..12 | ForEach-Object { curl.exe -s -o NUL -w "$_ : %{http_code}`n" -X POST -H "Content-Type: application/json" -d "{}" https://YOUR-API-HOST.onrender.com/api/trips/analyze }
```
Expected for step 3: ten `400` lines, then `429`. Then, from a phone on mobile data (a different
client address), send one request; it should return `400`, not `429`. If the phone gets `429`,
every visitor shares one bucket and `NUM_PROXIES` is wrong for this setup.

## Notes and limits

- Free web services spin down when idle, so the first request after a pause can be slow. See
  Render's current free-tier documentation for exact behaviour.
- `/api/health` is exempt from the HTTPS redirect so a health probe over plain HTTP is not redirected.
- Gunicorn runs one worker with four threads so the in-memory throttle counters and caches live in a
  single process.
- Rotate any key or token that was ever pasted into a chat, a screenshot or a commit.
